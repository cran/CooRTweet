Introduction to CooRTweet

Nicola Righetti & Paul Balluff

Overview

The CooRTweet package is a R tool for detecting and analyzing coordinated behavior across social media platforms. Named after Twitter, a quintessential site for coordinated message amplification through its features like hashtags and trending topics, CooRTweet is applicable to any social media platform, enabling analysis on mono-platform, multi-platform, and cross-platform datasets. Besides being platform-independent, it is also content-independent, supporting a wide range of content types (including hashtags, URLs, images, and any other objects of interest to the researcher). The package allows for flexible thresholds to identify coordination while also accounting for the uncoordinated network in which the coordination is contextualized. CooRTweet is one of the first software tools for coordinated detection to have undergone rigorous validation. With its output, researchers can effectively explore networks of coordinated activity.

The methodological rationale and a cross-platform case study are described in the CooRTweet paper (Righetti and Balluff 2025).

Installation

You can install the CooRTweet package from CRAN or GitHub:

# Install from CRAN
install.packages("CooRTweet")

# Or install the development version from GitHub
devtools::install_github("nicolarighetti/CooRTweet")

Key Features

  1. Flexible Data Handling: Works with mono-modal, multi-modal, and cross-platform datasets, and any type of object.
  2. Customizable Thresholds: Set time intervals and repetition/edge-weight thresholds to detect coordinated activities.
  3. Graph-Based Analysis: Outputs coordination networks as igraph objects for further analysis and visualization.
  4. Included Data: Comes with datasets for learning Righetti et al. (2022) and a simulate_data function to generate synthetic coordinated networks. The installed package includes german_elections_sample, an anonymized excerpt for examples, not the full published study.

Getting Started

Input Data Format

The input dataset should include the following columns. prep_data() can rename source columns to these names and, by default, removes rows with missing values and duplicate shares. Use drop_na = FALSE or drop_duplicates = FALSE to retain them.

  • object_id: A unique identifier for the shared content (data type: character).
  • account_id: The user account identifier (data type: character).
  • content_id: The unique ID of the post (data type: character).
  • timestamp_share: The timestamp when the content was shared (data type: integer, UNIX format).

Detect Coordinated Groups

Use the detect_groups() function to find groups of accounts coordinating within a specified time window.

  x = russian_coord_tweets,
  min_participation = 2,
  time_window = 60

Select an Inclusive Time Interval

Set time_window_low to select one interval of time differences. Both limits are included. The shares below occur at 0, 10, and 30 seconds; selecting 10 through 20 seconds keeps the pairs exactly 10 and 20 seconds apart:

shares <- data.table::data.table(
  object_id = "url_1",
  account_id = c("A", "B", "C"),
  content_id = c("p1", "p2", "p3"),
  timestamp_share = c(0, 10, 30)
)

interval_result <- detect_groups(
  shares, time_window = 20, time_window_low = 10,
  min_participation = 1
)
sort(interval_result$time_delta)
#> [1] 10 20

The default time_window_low = 0 also includes pairs shared at the same second.

Generate Coordination Networks

Convert detected groups into a coordination network using generate_coordinated_network(). By default, the function returns the graph filtered by the median edge weight (edge_weight = 0.5, subgraph = 1). This is the conventional coordinated-sharing network of accounts connected by repeated sharing (e.g., Giglietto et al. (2020)); the edge-weight threshold can be adjusted. To return the full graph instead, set subgraph = 0; its weight_threshold edge attribute is 0 if an edge does not exceed the threshold and 1 otherwise.

graph <- generate_coordinated_network(result)
graph

Advanced Usage

Multi-Modal and Multi-Platform Analysis

To analyze multiple types of content (e.g., URLs and images), run detect_groups() separately for each type and combine the results.

german_elections_sample is included in the installed package. It contains 97,413 anonymized rows from 15 August through 7 September 2021 (UTC), drawn from the data used by Righetti et al. (2022). It includes Facebook and Twitter posts and illustrates both URL and image coordination. It is a temporal excerpt for learning, not a representative sample or the full study dataset, and cannot reproduce the paper’s figures.

The full anonymized german_elections dataset is not installed with the package. It is available in the CooRTweet source repository at data-raw/german_elections_full.rda. From the root of a source checkout, load("data-raw/german_elections_full.rda") creates the german_elections object. The paper reproduction script is at vignettes/reproduce_examples.Rmd in that checkout; it is not an installed package vignette. Some panels require non-public data and are commented out in the public script.

First we prepare shared URLs:

# URLs
urls_data <- prep_data(german_elections_sample,
                       object_id = "url_id",
                       account_id = "account_id",
                       content_id = "post_id",
                       timestamp_share = "timestamp")

urls_data$object_id <- paste0("url_", urls_data$object_id)

Next, we prepare images. We used the pHash algorithm to uniquely identify images. The algorithm is implemented in the OpenImageR package (Mouselimis 2023).

# images (pHash)
img_data <- prep_data(german_elections_sample,
                      object_id = "phash_id",
                      account_id = "account_id",
                      content_id = "post_id",
                      timestamp_share = "timestamp")

img_data$object_id <- paste0("hash_", img_data$object_id)

Next, we perform the first step of coordination detection on each subset of the data with the detect_groups function:

# Detect coordinated groups for URLs and images  --------------------
result_urls <- detect_groups(urls_data, time_window = 30,
                             min_participation = 2)

result_images <- detect_groups(img_data, time_window = 30,
                               min_participation = 2)

To study only URL shares 10 to 30 seconds apart, we can make a separate call. Both 10 and 30 seconds are included:

result_urls_10_30 <- detect_groups(
  urls_data, time_window = 30, time_window_low = 10,
  min_participation = 2
)
head(result_urls_10_30)

Then we can simply stack the original URL and image results:

# Combine results  --------------------
library(data.table)

combined_results <- rbindlist( 
    list(result_urls, result_images),
    use.names = TRUE,
    fill = TRUE
)

Now we can generate a filtered network with subgraph = 1 (also the current default) to find accounts that show coordinated behavior in terms of image and URL sharing. The input includes both platforms, but the filtered graph in this example has no Facebook–Twitter edges; including two platforms does not itself establish cross-platform coordination.

# Generate the coordinated multi-modal network  --------------------
graph <- generate_coordinated_network(combined_results, subgraph = 1)
graph

Visualization

Visualize the coordination network using igraph:

library(igraph)
plot.igraph(
    graph,
    layout = layout.fruchterman.reingold,
    edge.width = 0.5,
    edge.curved = 0.3,
    vertex.size = 3,
    vertex.frame.color = "grey",
    vertex.frame.width = 0.1,
    vertex.label = NA
)

Additional features

The CooRTweet package includes several additional functions and features that enable refined exploration of coordinated networks, as detailed in the package documentation.

Conclusion

The CooRTweet package enables researchers to study coordinated behaviors with a high degree of flexibility and precision. Its generalized architecture makes it adaptable to various contexts and datasets, empowering social media research and analysis.

Coordinated Sharing Detection Service powered by CooRTweet

CooRTweet also powers the Coordinated Sharing Detection Service, a web-based service built on a streamlined version of the R package. It enables data journalists, fact-checkers, researchers, and other practitioners to analyze and visualize patterns of coordinated sharing in social media data.
